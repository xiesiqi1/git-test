# STM32F103 五路循迹小车

面向 **2026 全国大学生电子设计竞赛 H 题《车载平衡滚球运动控制系统》** 的循迹底盘。
目标是在 H 题赛道上完成 **"从 A 点出发 → 跑满一整圈 → 自动停在 A 点"**，并预留声光提示与里程接口给后续的滚球控制部分。

赛道与指标（H 题）：

| 项目 | 数值 |
|---|---|
| 赛道构成 | 2 × 1.5 m 直线 + 2 × R 0.5 m 半圆（黑线宽 1.8 cm） |
| 一圈周长 | 6.142 m |
| 限时 | ≤ 20 s（平均 ≥ 0.31 m/s） |
| 停车偏差 | ≤ 2 cm |

当前实测：**一圈 25.5 s**，自动停车由**里程**判定（`LAP DONE`），压线判定作为并行入口保留。

功能一览：

- 五路红外循迹，开环 PWM + 比例 + **虚拟前视**（用 `LEAD_TICKS` 把探头"电气前移"，等效约 3.9 cm）
- 弯道按差速**成比例收油**，并带**独立上限**（避免收油被积分项叠加到地板）
- **自动停车双入口**：压停止线 / 里程跑满一圈，二者共用同一个断油函数
- 1.3" OLED 实时显示误差、差速、左右 PWM、探头状态、编码器里程（本工程无串口，屏是唯一调试窗口）
- 跑圈计时（本圈 / 上圈）、A/B 点声光提示、掉速档案（`BMIN` / `LMAX` / `SLOW@`）
- 传感器极性 / 转向极性可在**不重新编译**的情况下用按键标定，结果存 Flash

## 三、快速启动

### 1) 接线

按 `car.txt` 第一 ~ 五节接线。**最容易漏的一条：L298N 的 GND 必须与 STM32 的 GND 相连**，否则电机乱转或不动。

### 2) 编译

Keil 图形界面：打开 `MDK-ARM/Test1.uvprojx` → `Rebuild`（全量）→ 必须 **0 Error / 0 Warning**。

命令行（等价，便于脚本化）：

```bash
cd MDK-ARM
"C:/Keil_v5/UV4/UV4.exe" -r Test1.uvprojx -j0 -o build_log.txt
```

> `-r` 全量重建，`-b` 增量编译。**"0 Error / 0 Warning"是硬规矩**：本项目曾因注释少一个 `*/` 把下一行宏定义吞掉，编译器只给一条警告、不报错。

### 3) 下载

ST-Link + SWD 下载。`Options for Target → Debug → Settings → Flash Download` 里擦除方式选 **Erase Sectors**：

> ⚠ **不要用 Erase Full Chip**。传感器极性 / 转向极性标定值存在 Flash 尾部，全片擦除会退回默认值 —— 那会让车"突然朝赛道对角直冲"。

### 4) 上电自检

上电后 OLED 应显示自检画面，**蜂鸣器应安静**（一直响说明电平方向反了，改 `BUZZER_ACTIVE_LEVEL`）。
把两个轮子**架空**，长按 PA15 超过 0.8 s：左轮前进 1 s → 停 → 右轮前进 1 s → 停。用来确认电机接线、左右是否搞反。

### 5) 跑一圈

在起步位置的车轮下做个记号 → 短按 PA15 启动 → 车自动循迹一整圈 → 里程到 6.142 m 时**立即断油停车**，屏上第 1 行显示：

```
LAP DONE  T 25.5      ← 里程判定停车（T = 本圈成绩）
HIT LINE  T 25.5      ← 压停止线判定停车
```

两个标签就是"是哪个入口停的"的唯一线索。

### 6) 对准停车点（目标 ≤ 2 cm）

量车轮标记相对起步标记差了几厘米：

- 冲过头 → `STOP_MILEAGE_COUNT` **调小**
- 没到 → **调大**

标尺：**1 cm ≈ 2300 计数**（一圈 6.142 m = 1 400 000 计数）。
只改这一个数，**不要动 `MILEAGE_LAP_COUNT`** —— 它还管着 B 点提示的位置。

## 五、屏幕读数

运行时（6 行 × 21 字符）：

```
RUN  T12.3 L11.8     本圈 / 上圈计时
E  -2    LOST 0      夹线误差(-4~+4, 99=丢线) / 连续丢线拍数
B  32    DIFF -12    本拍基础速度(含收油) / 本拍下发的差速
L  44    R  20       左右轮 PWM
[ ][X][X][ ][ ]      五路探头，实心 = 压到黑线
ENC 1582 1204 M2     左右累计计数(÷1000) + 已到哪个标记点
```

停车后第 2、3、4 行换内容（`B/DIFF/L/R` 停车后没有信息量）：

```
BMIN 26/26 LMAX 0    本圈最小 base（看见线 / 含丢线拍）+ 最长连续丢线拍数
EVT  4  MAXW 5       宽线事件次数 / 整圈最宽一拍压了几路
SLOW@ 141K WIDE@ 850K  最慢那一拍的位置 / 首次触发的位置（单位：千计数）
```

## 六、注意事项

1. **CubeMX 重新生成代码会覆盖 `Core/*`、清掉 `Middlewares/u8g2/`、并可能把 HSE 改回 `RCC_HSE_OFF`**（那样上电没反应）。每次 Generate 后必须检查 `.ioc` 里 PD0/PD1 仍是 OSC_IN/OSC_OUT，以及 `SystemClock_Config()` 里的 `HSEState`。
2. `CtrlLoop()` 跑在 **SysTick 中断**里，任何地方都不能死等（声光提示用状态机 + 自动重装，不用 `HAL_Delay`）。
3. 跑动中**不要抬车、不要用手挡探头**：五路全黑会被判成"压到宽线"，门槛满足时会当场停车。
4. 本工程**没有串口**（PA9/PA2/PA3 已被电机与探头占用），唯一调试窗口是 OLED。
